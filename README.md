# 十字路の交通信号シミュレーション：右左折・場外待機対応版

HTML・CSS・JavaScript ES Modules・Three.jsだけで動くローカルアプリです。
React、Vue、TypeScript、ビルドツール、外部3Dモデルは使用していません。
Three.jsとOrbitControlsは同じCDNのバージョン0.180.0に固定しています。

## 起動

Python 3がある環境で、プロジェクトのフォルダから実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

http://127.0.0.1:8000/ を開いて「開始」を押してください。終了はターミナルでCtrl+Cです。
すでにこのフォルダを配信するHTTPサーバーが動いている場合は、そのページを再読み込みしてください。
HTMLのダブルクリックではなくHTTP経由で開きます。CDNへのインターネット接続とWebGL対応ブラウザが必要です。
アプリ起動にNode.jsやnpm installは不要です。


## GitHub Pagesでの公開

このリポジトリの `main` ブランチのルートをGitHub Pagesで配信します。
`.nojekyll` により、HTML・CSS・ES Modulesをそのまま静的ファイルとして公開します。
以後は `main` にプッシュするとGitHub Pagesが自動で更新されます。
公開URLと配信状況はリポジトリの **Settings → Pages**、配信処理は **Actions** で確認できます。

## 今回の改善

### 直進・右折・左折

4方向×3進路の12経路を、交通流モデルと3D表示で共用しています。
直進・左折・右折の選択は到着時に決まり、pendingで待つ間も入場後も変わりません。
初期比率は直進60％、左折20％、右折20％。左折と右折の割合を操作パネルで変更でき、残りが直進です。
左折＋右折は100％以下です。割合の変更は新しく到着する車両にだけ適用されます。

- 左側通行の車線を通り、右左折は接線が連続する円弧で正しい出口へ接続します。
- 曲線へ入る前に減速し、車体の向きも経路の接線に合わせて回転します。
- 右折は、対向先頭の直進・左折車が停止線から30m以内にいる場合に譲ります。
- 交錯する経路には同時に進入せず、停止線前で待ちます。交錯しない対向直進・対向左折は同時に進めます。
- 同一経路は車間制御により複数台が追従できます。1車線なので右左折待ちを追い越しません。
- 出口に空きがない場合は進入を待ちます。別方向から同じ出口に合流した後も共通の出口距離で追従します。
- 車間の制約に加えて、回転した車体の長方形でも重なりを防ぎます。
- 停止線へ進入済みの車両は、黄・赤でもその経路を最後まで進みます。
- 全赤時間の終了時に旋回車が残っている場合も、後端が交差領域を抜けるまで全赤を保持します。
- 選んだ出口から後端が道路端を越えると通過を計上し、車両を削除します。進路別の通過内訳も表示します。

これは交錯区間を安全側に予約する教育用モデルです。同時通行の許可は保守的で、実際の交差点の交通容量をそのまま再現するものではありません。

### 道路端の場外待機

各道路の端に淡い待機区画と、実際のpending列の先頭最大4台を表示します。
台数札は全待機台数と「先頭4台表示 ＋残りN台」を表示します。道路内に無理に詰めて車体を重ねません。
4台という上限は描画だけに適用し、交通流モデルはすべての到着要求をFIFOで保持します。

各要求は固有の到着ID・到着時刻・進路を持ちます。安全な入口の空きができると先頭から入場し、到着時刻・進路・場外待ち時間を引き継ぎます。
到着を破棄したり、統計と無関係のダミー車両を表示したりしません。
各道路端の台数、方向別の場外待機、場外待機合計は同じ列から算出します。

### 既存機能と統計

地面・道路・車線・停止線・方角、OrbitControls、東西/南北の信号、交通量・時間・速度の設定、実行操作を維持しています。
物理計算はdelta timeを積算した1/60秒刻み、表示は経路距離を補間します。
一時停止中は車両・pending・待ち時間・信号が停止し、視点だけを動かせます。

道路内の統計を維持し、場外を含む最大待ち行列・平均待ち時間・最長待ち時間を追加しています。
有限の道路内台数だけで渋滞が頭打ちになって見えないよう、道路内と場外を分けて併記します。

## 設定と操作

| 設定 | 初期値 | 入力範囲 |
| --- | --- | --- |
| 東西方向の交通量 | 24台/分 | 0〜120台/分 |
| 南北方向の交通量 | 24台/分 | 0〜120台/分 |
| 左折率 | 20％ | 0〜100％ |
| 右折率 | 20％ | 0〜100％、左折と合計100％以下 |
| 東西方向の青時間 | 20秒 | 5〜120秒 |
| 南北方向の青時間 | 20秒 | 5〜120秒 |
| 黄時間 | 3秒 | 0〜10秒 |
| 全赤時間 | 2秒 | 0〜10秒 |
| 速度 | 1倍 | 0.25〜10倍、0.25刻み |

交通量は軸の2方向を合わせた平均到着率です。東西24台/分なら、東と西にそれぞれ平均12台/分がランダムに到着します。
交通量・速度は即時反映。実行中・一時停止中に変更した信号時間は次に始まる区間から反映し、開始前の変更は最初の青時間から反映します。
信号は東西青→東西黄→全赤→南北青→南北黄→全赤の順です。全赤0秒でも交錯車両の通過確認を行います。

- 左ドラッグ：回転、ホイール：ズーム、右ドラッグ：移動。
- 3Dビューにフォーカスして矢印キー：移動。
- タッチは1本指で回転、2本指でズーム・移動。
- 「初期の視点に戻す」：場外区画まで見渡せる初期視点に復元。
- リセット：設定とカメラを保ち、車両・pending・測定・信号・乱数を初期化。
- タブを非表示にすると自動で一時停止。「再開」で続行。
- 狭い画面では開始・一時停止・再開・リセットを画面下に固定。

同じ設定でリセットすると同じ到着列・進路で比較できます。旋回率だけを変える場合も到着間隔の乱数列は同じです。
処理落ち時は1フレーム分の実時間を最大0.1秒として扱うため、重い環境では指定倍率より遅く進むことがあります。

## 測定の定義と整合性

| 項目 | 定義 |
| --- | --- |
| 発生車両数 | 道路上へ実際に追加した累計。pendingはまだ含めない |
| 通過車両数 | 選んだ出口から後端が道路端を越えて退出した累計 |
| 現在の車両数 | 発生−通過。道路上の全進路の車両 |
| 道路内の待機 | 停止線へ未進入かつ速度0.3m/s未満の車両数。右左折待ちを含む |
| 場外待機 | 到着済みだが入口の空きを待っている要求数 |
| 最大待ち行列（場外含む） | 1方向の道路内待機＋pendingの過去最大 |
| 道路内最大 | 従来どおり、1方向の道路内待機の過去最大 |
| 平均待ち時間（道路内） | 全発生車両の累積停止待ち時間の合計÷発生数。現在の車両・待ち時間0秒も含む |
| 最長待ち時間（道路内） | 1台の累積停止待ち時間の過去最大 |
| 場外を含む平均待ち時間 | 道路内停止待ち＋入場済み車両の場外待ち＋現在pendingの待ち、を全到着要求数で割った値 |
| 場外を含む最長待ち時間 | 1台の場外待ち＋道路内停止待ちの累計最大。現在pendingも含む |
| 進路別通過 | 直進・左折・右折それぞれの退出累計 |
| 経過時間 | 速度倍率を反映したシミュレーション時間 |

常に「発生＝通過＋現在」「全到着＝発生＋pending」「通過＝直進通過＋左折通過＋右折通過」が成立します。
場外の待ち時間は到着時刻から求め、入場時に確定して引き継ぐため二重計上しません。

## ファイル構成

```text
3DSimulatorLearn/
├── .gitignore                 # 生成物とmacOSメタデータを除外
├── .nojekyll                  # GitHub Pagesでそのまま静的配信
├── index.html                 # 日本語UIとCDNのimport map

│   ├── road.js                # 地面・道路・標示
│   ├── routes.js              # 全12経路・車体判定・交錯表
│   ├── scene.js               # カメラ・照明・OrbitControls
│   ├── signals.js             # 信号サイクル・全赤保持
│   ├── simulation.js          # 到着FIFO・右左折・追従・合流・測定
│   ├── traffic-view.js        # 車体・旋回表示・場外車両・台数札
│   └── ui.js                  # 入力検証・日本語表示
├── tests/
│   ├── simulation.test.mjs    # 従来機能の回帰テスト

```

1単位は1m。東が+x、上が+y、南が+zです。地面120m四方、道路幅12m、車長4.2m、車間2mを基本としています。

## テスト

Node.jsがある環境で実行できます（検証環境：26.7.0、外部パッケージ不要）。

```sh
node --test tests/*.test.mjs
```

22件のテストで、従来の信号・時間変更・停止/再開・リセット・設定範囲、12経路の接続、対向車優先、合流後の追従、旋回中の全赤保持を検証します。
混合交通・右折100％・左折100％の各最大交通量を、黄/全赤0秒で動かし、車体衝突・信号無視・台数欠落がないことを独立した車体四隅の計算で確認します。
FIFOの進路維持、場外待ち時間の二重計上防止、需要停止後の全車退出、フレームレートと速度倍率の整合も検証します。
